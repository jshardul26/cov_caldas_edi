## 1. TOTAL SCOPE OF THE PROJECT (unchanged from original brief, now COVID-specific)

1. ~~Freeze a scientifically defensible disease + dataset pair~~ → **Frozen: COVID-19, two-stage task (see §4).**
2. Verify datasets first-hand (sample counts, metadata completeness, license, linkage) — no fabricated stats.
3. Literature review with a genuine, non-overclaimed research gap.
4. Leakage-safe, **patient-level** preprocessing pipeline for images + metadata, across **two source datasets**.
5. EDA with class balance / missingness / patient distribution reporting, **including cross-dataset domain-shift checks**.
6. ML baselines: Logistic Regression, Random Forest, XGBoost on metadata.
7. DL: CNN/transfer-learning image branch; MLP metadata branch.
8. Multimodal fusion architecture — **two heads**: Stage 1 (COVID positive vs. negative) and Stage 2 (severity, positives only).
9. Ablation study: image-only vs. metadata-only vs. fused, **for each stage**.
10. Full evaluation suite: ROC-AUC, PR-AUC, F1, recall, specificity, precision, confusion matrix, calibration — **per stage**.
11. Explainability: Grad-CAM (image branch), SHAP (metadata branch).
12. External/cross-dataset validation where feasible.
13. Reproducibility: seeds, saved checkpoints, config files, requirements.txt, no hardcoded local paths.
14. Streamlit demo app (upload image + metadata → prediction + probability + Grad-CAM + SHAP), with a visible "not a clinical diagnostic tool" disclaimer.
15. Research paper draft mapped to the 20-section structure (abstract → references).
16. Four clearly divided team roles with shared/overlapping checkpoints so the team doesn't fracture into 4 disconnected projects.
